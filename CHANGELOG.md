## [Unreleased]

### Added
- **Archetypal Architecture, a third deck (`decks/archetypes/`)**: Sixteen archetype cards in five families - Order & Stability, Mastery & Risk, Belonging & Connection, Independence & Fulfillment, and Narrative Functions. Each card prints what the archetype wants, what it dreads, how it speaks, the words it uses and never uses, its shadow, its anchors, and a figure drawn by one of sixteen new parametric shapes. The deck uses the block engine: its verso is voice traits, lexicon, forbidden phrasing, shadow and anchors, and its on-voice example is `"card": false`, so it prints in the rules and the skill but not on the card. Its schema requires every declared block and sets `minItems: 1`; `scripts/test/archetypes.test.mjs` proves a missing block fails validation, and checks each id, name and family against an extraction of the sixteen card headings committed at `decks/archetypes/data/source-headings.json`. Thirty-two-page PDF at 216 x 360 pt, byte-identical on rebuild; `DECISIONS.md` §43-45 record the family split, the figures and the measured accents.
- **A deck can declare what its card backs print (`deck.json` `blocks`)**: A deck whose cards are not a checklist declares an ordered list of `{ field, label, style }`, with `style` one of `traits`, `words`, `quotes`, `prose`, `list` or `example`, and the print verso, the web verso and the generated rules, skill and resources all render that list under the deck's own headings. `fields.items` and `fields.antiPattern` may be `null`, which omits those sections entirely rather than printing a heading over nothing; a block whose field a record does not carry is skipped the same way. A deck that declares no blocks takes the path it always took: both shipped decks' PDFs (UX `40164666…` at 1,069,546 B, narrative `94b0577f…` at 758,238 B) and every generated web, rules and skill file are unchanged, byte for byte. `scripts/test/blocks.test.mjs` builds a block deck invented inside the test through validate, the generators, a real browser and Typst, and `DECISIONS.md` §42 records the contract.
- **The repository now holds more than one deck (`decks/`)**: Each deck owns its records, schema, families, accents, prose and output paths under `decks/<slug>/`, and the engine under `packages/` reads them from `deck.json` instead of naming a deck. The web root gains a generated `packages/web/index.html` that lists every deck with its card count and links to its viewer, and every command accepts `--deck <slug>` while still running over every deck by default. The UX deck moved to `decks/ux-laws/` with its printed pages, viewer bundle, ruleset and skill unchanged, byte for byte.
- **Narrative Architecture, a second deck (`decks/narrative/`)**: Forty-eight story-structure cards in four families of twelve - Arc & Plot, Persuasion & Pitch, Corporate & Technical, and Rhetorical Micro-tactic. It declares its own schema and field names (`family`, `steps`, `origin`, `figure`), prints numbered beats instead of checkboxes, and reads family by family (`printOrder: "family"`). Seven cards carry a writing prompt on the back; nine carry a year before the common era and print it as BCE rather than as a negative number. Two titles are renamed so the deck's naming stays its own: PRS-07 *The Story Spine* and PRS-09 *The Insight-Led Challenge*, both with their original source. Seven new figure shapes draw its diagrams. Its print PDF, phone viewer, agent ruleset and skill are generated from the same records as every other artifact.

### Changed
- **The schema's year field no longer has a floor (`data/law-schema.json`)**: `academicOrigin.year` accepts any integer up to 2100, and the description records that a negative year means BCE while printing one is not implemented. The floor of 1800 dated from the first commit, was never documented, and encoded the range of the current corpus rather than a property of a source - it had already put Ockham's c. 1320 out of reach for HMM-07. `DECISIONS.md` §38 records both bounds as typo catchers and the deferred BCE format.

### Fixed
- **The archetype test read the research input, which is not in git, so CI failed on `bf91451`**: `scripts/test/archetypes.test.mjs` extracted the sixteen card headings from `SupportingInformation/03 - Archetypes/`, a gitignored folder that exists only in a working copy carrying the research. It passed locally and failed on every clean checkout, which is what CI is: run 42878987087 failed at *Tests and gate* with `ENOENT` while the per-deck jobs passed. The extraction now lives in `decks/archetypes/data/source-headings.json`, written by `scripts/extract-source-headings.mjs` with the source's path and sha256; the test always compares the records to that file and, where the input is present, re-extracts and requires the two to agree. `DECISIONS.md` §46 records what it proves and what it does not.
- **A test build no longer leaves its invented deck in the shared print build directory (`packages/prepress/build.mjs`)**: `build.mjs` now takes an explicit `--build-dir`, defaulting to `packages/prepress/build` as before, and the tests that build a deck invented in a scratch directory use it. Previously `npm test` finished with the fixture's `cards.json` in the shared directory, so a direct `typst compile` - or any later build that reused it - printed the fixture instead of the committed deck. A test now asserts that the shared directory still holds a committed deck and that an isolated build leaves its bytes untouched.
- **HMM-06 drew three output boxes under a caption saying "EMIT ONE"**: Postel's Law now draws one output block, centred on the funnel's throat, and the record no longer declares `variants`, a parameter the shape clamps to its three glyph templates and which therefore could not change the drawing. The gate's SVG check failed on that parameter; the wrong drawing was in the deck from the first commit.

- **Adjudication join (`packages/triage/`)**: A record of what a person found when they checked each judge finding, and a tool that joins it to a report. A finding becomes a defect only after someone looks at the source; until now that work lived in a chat message. The record is keyed to the artifact's sha256, so verdicts written against one version are refused by another (exit 3) rather than quietly applied, and an adjudication that fails validation is an error (exit 2) rather than an empty one — a file the tool could not read must never report "0 unadjudicated". Matching uses the same normalised 80-character quote key the panel uses for convergence, and `also` lets two judges' wordings of one defect carry one verdict. `verified` requires a `file:line` or `§N` pointer, `rejected` requires a reason, `duplicate` names the record it duplicates, and an `open` template record counts as no verdict, so a freshly generated skeleton cannot report complete. `packages/triage/README.md` states the limits, including that the tool checks that evidence was named, not that it is true.

### Changed
- **Card schema: checklist items carry a kind (`data/law-schema.json`, all 34 records)**: A checklist item is now `{text, kind}` where `kind` is `code` or `research`. Six of the 113 items are `research` - MPA-02's recall test, MPA-05's anchored-estimate comparison, MPA-07's two process instructions, MPA-09's framing test, and TME-05's time-on-task measurement - because an agent reading code cannot perform them. The generated ruleset and skill resources print those six with a note saying so, which is the difference between an agent reporting the gap and claiming a check it never made. The print surface is unchanged: the PDF built from the migrated records is byte-identical to the previous build, 68 pages, 743,518 bytes, md5 `6292e2e8`, which is the evidence that this is a data change rather than a layout change. `DECISIONS.md` §36 records the classification and the print decision.
- **Skill layout (`packages/rules/generate.mjs`, `skills/ux-laws/`)**: `skills/ux-laws/SKILL.md` is now a 6,222-byte index and the card bodies live in five generated `skills/ux-laws/resources/<category>.md` files, the largest 9,530 bytes, where the single skill file was 28,023 bytes loaded whole on every triggered session. The index carries the frontmatter, the rules that hold across every card, and a table per category of ID, name and the card's own trigger sentence, which is the field that decides whether the card applies; the resource file carries the axiom, checklist, anti-pattern pair and source. The description drops "or long lists", because no card covers them and a description is a promise the body has to keep. `rules/ux-rules.md` stays whole: it is pasted into a prompt, not loaded as a skill. `scripts/accept.mjs` now reads the resource files from disk for its committed-bytes and generator checks, so a category added later is checked without editing the gate. `DECISIONS.md` §35 records the measured sizes and what the split costs: the agent must choose a file, and a vague trigger is now a routing defect as well as a content one.
- **House spelling (`data/laws/mpa-02.json`, `data/laws/tme-09.json`)**: The new Von Restorff record used the British "neighbours" and "Emphasise", where the deck's copy is US, as HMM-01 and the README already were. Both words are now "neighbors" and "Emphasize". TME-09 is already published, so the change corrects a line on the printed card; MPA-02 is new in this release.
- **PDF build (`packages/prepress/build.mjs`)**: The build pins `SOURCE_DATE_EPOCH` to a fixed deck epoch (2026-11-09T00:00:00Z), because Typst otherwise stamps `/ModDate` and derives the trailer `/ID` from the compile time. Two builds of one commit are now byte-identical - measured at 579,849 bytes on the twenty-four-card deck that change was made against, and at 687,578 bytes on the thirty-card deck in this release; two without the pin differ in those fields while both files are the same length. An inherited `SOURCE_DATE_EPOCH` overrides the pin, and a non-integer is rejected rather than ignored. `DECISIONS.md` §29 records the choice and what it does not prove; the README's determinism paragraph now covers the PDF.
- **Split-bar diagram (`scripts/svg.js`)**: Row labels sit at the track's left edge, and the threshold is drawn per bar rather than as one rule across the drawing, because the single rule struck through the labels above and below each track. `DEC-03` and `DEC-05` are already published and were re-rendered and inspected after the change; `DECISIONS.md` §23 records it.
- **Web smoke test (`scripts/check-web.mjs`)**: The expected card count and the filter expectation are read from `data/laws/` at run time instead of being written as constants, so growing the deck no longer requires editing the test. Verified by deleting a record: the test fails naming both the rendered and expected counts.
- **Header icon (`media/icons/`, `media/icon.png`)**: The header icon is now a transparent WebP set at 1024, 512, 256, 192, and 128 px under `media/icons/`, replacing `media/icon.png`, which is removed, so any existing reference to the old path now 404s. The sizes were produced once with sharp used as a throwaway tool; it is not a dependency, and no generator is committed.

### Fixed
- **Citations (`packages/prepress/src/card.typ`, `packages/web/app.js`, `packages/rules/generate.mjs`)**: The Source line appended a period after any title, so a title ending in a question mark printed `Resource?.`. The added stop is now suppressed when the title already ends in `?`, `!` or `.`, in all four renderers that print it; the general rule also corrected `DEC-04`, whose title ends the same way. ## [0.1.0] - 2026-11-09

### Added
- **Canonical schema (`data/law-schema.json`)**: JSON Schema draft 2020-12 for one reference card, with `additionalProperties: false` at every object level, a fixed five-value category enum, and a nine-field card anatomy.
- **First deck records (`data/laws/*.json`)**: Six cards across five categories — Jakob's Law, the Law of Proximity, Hick's Law, Miller's Law, Fitts's Law, and the Serial Position Effect — each with an axiom, trigger, checklist, anti-pattern pair, graphic metaphor, and one primary academic source.
- **Parametric SVG generator (`scripts/svg.js`)**: Six diagram shapes (`network`, `hierarchy`, `proximity-grid`, `target-vector`, `decay-curve`, `convention-grid`) drawn from each card's `graphicMetaphor` parameters, with a 400 x 400 viewBox, `currentColor` marks, and `non-scaling-stroke` on every stroke.
- **Print template (`packages/prepress/src/card.typ`, `packages/prepress/build.mjs`)**: Typst template for a 3.00 x 5.00 in page (2.75 x 4.75 in trim plus 0.125 in bleed), a 0.1875 in safe inset, corner trim marks, and recto/verso faces. The build emits `packages/prepress/dist/ux-deck.pdf`. **The PDF has not yet been rendered: Typst is absent on the development machine.**
- **Static web viewer (`packages/web/`)**: Phone-friendly card viewer with no build step and no server. The card data and generated SVG are bundled into a classic script at build time so the page works from `file://`; cards flip to the verso by click or keyboard, and category filters narrow the deck.
- **Generated agent ruleset (`packages/rules/generate.mjs`, `rules/ux-rules.md`, `skills/ux-laws/SKILL.md`)**: The same records rendered as an actionable ruleset and as a skill with a trigger-oriented description.
- **Validation (`scripts/validate.mjs`)**: Ajv 2020 compilation of the schema, per-record error output, duplicate-ID detection, and a 15-word axiom check on top of the schema's 110-character cap. Accepts optional file paths for ad hoc checks; a deliberately broken record fails with the extra-property and missing-remediation errors.
- **PDF check (`scripts/pdf-check.mjs`)**: Structural check that every page's MediaBox is 216 x 360 pt and that the page count is twice the card count; handles raw and compressed object streams and exits 2 with a clear message when no PDF exists.
- **Web check (`scripts/check-web.mjs`)**: Headless Chrome/Chromium smoke test at a true 390 x 844 viewport, asserting no horizontal overflow, six rendered cards, a flip that exposes the verso, and a category filter that narrows to one card.
- **Licences (`LICENSE`, `LICENSE-DATA`)**: MIT for code and CC0-1.0 for card data and the schema.
- **Repository hygiene (`.gitignore`)**: Ignores `node_modules/`, Prepress build and dist output, `.DS_Store`, and the read-only `SupportingInformation/` research input.
- **Documentation (`README.md`, `CHANGELOG.md`, `DECISIONS.md`)**: Setup and verification instructions, the change record, and the reasons behind every deviation from the source specifications.

### Changed
- **Citations (`data/laws/dec-01.json`, `data/laws/mpa-01.json`)**: Each card now carries exactly one primary paper with that paper's own authors, year, title, and venue. DEC-01 cites Hick (1952), and the card is named Hick's Law to match; MPA-01 cites Murdock (1962). Merged attributions were removed deck-wide.
- **Schema requirements (`data/law-schema.json`)**: Removed `remediatedPattern` from `required[]` without declaring it, because the source schema required a property it never defined and `additionalProperties: false` made every record invalid. The `antiPattern { violation, remediation }` pair remains the single remediation field.
- **Schema identifier (`data/law-schema.json`)**: `$id` now points at the intended published URL, `https://raw.githubusercontent.com/tjmustard/knowledge-domain-decks-skills/main/data/law-schema.json`, replacing the `.example` placeholder. It is live only once this slice is merged to `main`; until then it is the intended canonical location, not a resolvable identifier.
- **Package name (`package.json`, `package-lock.json`)**: Renamed to `knowledge-domain-decks-skills` to match the repository slug.

### Fixed
- **Dead parameters (`data/laws/hmm-01.json`, `data/laws/ges-01.json`)**: Removed unused `panels` and `clusters` values from `parametricParams`; only parameters the SVG generator reads remain.
- **Page-count report (`packages/prepress/build.mjs`)**: The build log now reports the actual 12 pages (six cards, recto and verso) instead of six.
- **PDF check robustness (`scripts/pdf-check.mjs`)**: Compressed object streams are inflated before scanning, so a valid PDF is no longer misread as having no pages, and a missing PDF exits 2 with a build hint rather than a stack trace.
