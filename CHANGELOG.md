## [Unreleased]

### Added
- **Adjudication join (`packages/triage/`)**: A record of what a person found when they checked each judge finding, and a tool that joins it to a report. A finding becomes a defect only after someone looks at the source; until now that work lived in a chat message. The record is keyed to the artifact's sha256, so verdicts written against one version are refused by another (exit 3) rather than quietly applied, and an adjudication that fails validation is an error (exit 2) rather than an empty one — a file the tool could not read must never report "0 unadjudicated". Matching uses the same normalised 80-character quote key the panel uses for convergence, and `also` lets two judges' wordings of one defect carry one verdict. `verified` requires a `file:line` or `§N` pointer, `rejected` requires a reason, `duplicate` names the record it duplicates, and an `open` template record counts as no verdict, so a freshly generated skeleton cannot report complete. `packages/triage/README.md` states the limits, including that the tool checks that evidence was named, not that it is true.
- **Four cards closing Memory, Perception & Attention (`data/laws/mpa-08.json` to `mpa-11.json`)**: Sunk Cost Fallacy, Loss Aversion, Goal-Gradient Effect, and Status Quo Bias. The memory section now carries all eleven laws the research list places there (44-54); the deck is thirty-four cards and the print build sixty-eight pages. Each source was checked against Crossref before its record was written: Arkes & Blumer (1985), Kahneman & Tversky (1979), Kivetz, Urminsky & Zheng (2006), and Samuelson & Zeckhauser (1988).
- **Four diagram shapes (`scripts/svg.js`, `data/law-schema.json`)**: `sunk-gate` puts a spent block behind a "now" line with the decision arrow running on past it; `gain-loss-bars` draws two equal bars from one baseline, the loss solid and the gain a faint surface, so no ratio is asserted and hollow keeps its one meaning; `goal-gradient` draws effort accelerating toward a marked goal; `default-fork` draws the default at full weight and the alternative thinner, both ending in solid dots. The deck has twenty-three shapes across thirty-four cards. `DECISIONS.md` §34 records why each exists, the measured label clearances, and the attributions.
- **Attribution and pairing decisions (`DECISIONS.md` §34)**: Sunk cost cites Arkes & Blumer (1985) and does not blend Staw (1976), which is escalation of commitment; loss aversion cites Kahneman & Tversky (1979) and prints no ratio, because the 2-to-2.5 figure is Tversky & Kahneman (1992), DOI 10.1007/BF00122574, and that paragraph is its only home; goal gradient cites Kivetz, Urminsky & Zheng (2006), with Hull (1932) recorded as the name's origin in deliberate contrast to TME-09. Loss aversion is recorded as a departure from the specification text, which attached the ratio to the 1979 paper. Status quo bias constrains its own checklist: it may make a default visible, reversible, or explicitly chosen, and may not instruct anyone to set one because people will not change it. The three pairings are recorded and their partners left alone - DEC-08, TME-04, DEC-03/DEC-11 - and sunk cost is recorded as pairing with nothing published.
- **Cross-model audit panel (`packages/judges/`)**: A runner that puts one artifact in front of models from separate families and writes a report of what each of them claims is wrong. It exists because the audit that produced the seven findings against the thirty-card skill was a throwaway script: model calls, hand-assembled prompts, and verdicts read out of a directory by eye. A run writes the artifact's exact bytes and hash, the exact prompt, one file per model, and a report whose header says that nothing in it is adjudicated. Three checks are load-bearing: the context window is explicit per judge and a prompt that the server read fewer tokens than it can possibly cost is marked truncated; models that ignore the output schema are supported by extracting the last parseable JSON object from their prose; and the panel refuses to run when every judge shares the artifact's authoring family. Models the panel declines to ask are named under **Not run** with the reason, so the judge table is not mistaken for the whole field of models. Measured on the thirty-card skill: glm reports 6-7 findings at ~265 tokens/s, kimi reports a long list of one class of objection, and qwen3.5:4b is excluded because a 4096-token context cannot hold the artifact. `packages/judges/README.md` records the per-model measurements and the extraction rules.
- **Six Memory, Perception & Attention cards (`data/laws/mpa-02.json` to `mpa-07.json`)**: Von Restorff Effect (Isolation Effect), Zeigarnik Effect, Peak-End Rule, Anchoring Bias, Selective Attention and Attentional Bottleneck, and Confirmation Bias. The research list's memory section runs 44-54; this slice writes the six cards at laws 44 and 46-50, because law 45 is the Serial Position Effect already published as MPA-01. The deck is thirty cards and the print build sixty pages.
- **Four diagram shapes (`scripts/svg.js`, `data/law-schema.json`)**: `odd-one-out` draws one distinct mark in a field of uniform neighbors; `peak-end-curve` marks the peak and the ending of an episode and draws no average; `anchor-line` shows estimates gathering near an initial number; `filter-gate` passes one of several inputs through a filter. Zeigarnik reuses `paired-panels` and Confirmation Bias reuses `split-bar`, so the deck has nineteen shapes across thirty cards. `DECISIONS.md` §30 records why each exists and the measured label bounds.
- **Source and process decisions (`DECISIONS.md` §30-33)**: Zeigarnik is cited without a DOI and with the reason the volume-9 Crossref record cannot be attached to her paper; Confirmation Bias pairs a broad axiom with Nickerson and corrects the Repository's pairing with Wason; Selective Attention asserts the observable rather than any one attention model, in the diagram as well as the axiom; an ID is recorded as a stable key rather than a position; §31 records the rule that an instrument which can return a plausible wrong answer must fail loudly instead; §32 records that a card's axiom, trigger, diagram and checklist are one argument; §33 records that the schema's 110-character axiom limit is not a page-fit guarantee.
- **Six cards closing Time, Motion & Ergonomics (`data/laws/tme-05.json` to `tme-10.json`)**: Power Law of Practice, Keystroke-Level Model, Weber-Fechner JND Law, Gilbreth Motion Economy, Crossman's Velocity Law (Welford's Variant), and Visual Saccadic Latency Law. Time, Motion & Ergonomics now carries all ten laws the research list places in that section (34-43), with this slice adding the last six (38-43); the deck is twenty-four cards and the print build forty-eight pages.
- **Five diagram shapes (`scripts/svg.js`, `data/law-schema.json`)**: `power-curve` draws a steep early fall that flattens and declares `monotoneDown: true`; `ratio-scale` puts the same values on value-spaced and ratio-spaced axes; `reach-map` draws a phone, a thumb-zone target, a far-corner target, and the travel between them; `difficulty-line` plots movement time against log2(D/W + 0.5); `scan-path` alternates fixations and saccades. The keystroke model reuses `split-bar`, so the deck has fifteen shapes across twenty-four cards. `DECISIONS.md` §27 records why each exists.
- **Source decisions (`DECISIONS.md` §26)**: Weber is cited alone because the axiom is his ratio, not Fechner's logarithm; the 1911 *Motion Study* title page names Frank Gilbreth alone, so the card corrects the Repository and records Lillian Gilbreth's actual collaboration; Welford is cited because the printed formula is his log2(D/W + 0.5), with Crossman's unpublished thesis and Crossman & Goodeve's overshoot account distinguished from it; Dodge is cited alone with Rayner as the later synthesis, and the saccade law is recorded as motion rather than attention.
- **Six cards closing Decision-Making and opening Time & Motion (`data/laws/dec-09.json` to `dec-11.json`, `tme-02.json` to `tme-04.json`)**: Simon's Bounded Rationality and Satisficing, Cognitive Absorption, Decision Fatigue, Accot-Zhai Steering Law, Doherty Threshold, and Perceived Performance Heuristics. Decision-Making now carries all eleven laws the research list places in that section (23-33); the deck is eighteen cards and the print build thirty-six pages.
- **Two diagram shapes (`scripts/svg.js`, `data/law-schema.json`)**: `steering-tunnel` draws two corridors of one length at different widths, and `decline-curve` draws a monotone fall with every label a parameter. The second declares `monotoneDown` on the shape itself, so the acceptance gate samples the drawn path and fails if it turns back up; `decay-curve` declares `false` and is checked for nothing. Neither claim is global, because the recall curve is a U on purpose.
- **Citation and scope decisions (`DECISIONS.md` §16-24)**: Decision Fatigue cites Baumeister et al. (1998) but asserts the observable rather than the ego-depletion mechanism, which Hagger et al. (2016) failed to replicate; Cognitive Absorption cites Agarwal & Karahanna alone; Doherty cites IBM Technical Report GE20-0752-0 with no page count, because the two sources that confirm the report disagree on its extent; Perceived Performance cites Seow with Miller as antecedent; §16 records why no check joins prose about an artifact to the artifact.
- **Six decision-making cards (`data/laws/dec-03.json` to `dec-08.json`)**: Tesler's Law, Choice Overload, Cognitive Load Theory, Working Memory Capacity Model, Cognitive Friction, and Framing Effect, each citing one exact primary source.
- **Two diagram shapes (`scripts/svg.js`, `data/law-schema.json`)**: `split-bar` shows a fixed total moving between two parties, and `paired-panels` compares two sets of cells side by side; neither is expressible with the existing six shapes. Both are in the schema's shape enum, and `DECISIONS.md` §15 records why they exist and what a filled mark means.
- **Citation and scope decisions (`DECISIONS.md` §12-14)**: Tesler's Law cites Saffer (2007) because its own attribution is a c. 1984 personal communication with no paper to cite; Cognitive Friction cites Cooper (1999), a trade book, because that book named the construct; Miller's Law and Working Memory Capacity ship as two cards by the project owner's decision, with the differentiation between them recorded.

### Changed
- **House spelling (`data/laws/mpa-02.json`, `data/laws/tme-09.json`)**: The new Von Restorff record used the British "neighbours" and "Emphasise", where the deck's copy is US, as HMM-01 and the README already were. Both words are now "neighbors" and "Emphasize". TME-09 is already published, so the change corrects a line on the printed card; MPA-02 is new in this release.
- **PDF build (`packages/prepress/build.mjs`)**: The build pins `SOURCE_DATE_EPOCH` to a fixed deck epoch (2026-11-09T00:00:00Z), because Typst otherwise stamps `/ModDate` and derives the trailer `/ID` from the compile time. Two builds of one commit are now byte-identical - measured at 579,849 bytes on the twenty-four-card deck that change was made against, and at 687,578 bytes on the thirty-card deck in this release; two without the pin differ in those fields while both files are the same length. An inherited `SOURCE_DATE_EPOCH` overrides the pin, and a non-integer is rejected rather than ignored. `DECISIONS.md` §29 records the choice and what it does not prove; the README's determinism paragraph now covers the PDF.
- **Split-bar diagram (`scripts/svg.js`)**: Row labels sit at the track's left edge, and the threshold is drawn per bar rather than as one rule across the drawing, because the single rule struck through the labels above and below each track. `DEC-03` and `DEC-05` are already published and were re-rendered and inspected after the change; `DECISIONS.md` §23 records it.
- **Web smoke test (`scripts/check-web.mjs`)**: The expected card count and the filter expectation are read from `data/laws/` at run time instead of being written as constants, so growing the deck no longer requires editing the test. Verified by deleting a record: the test fails naming both the rendered and expected counts.
- **Header icon (`media/icons/`, `media/icon.png`)**: The header icon is now a transparent WebP set at 1024, 512, 256, 192, and 128 px under `media/icons/`, replacing `media/icon.png`, which is removed, so any existing reference to the old path now 404s. The sizes were produced once with sharp used as a throwaway tool; it is not a dependency, and no generator is committed.

### Fixed
- **Citations (`packages/prepress/src/card.typ`, `packages/web/app.js`, `packages/rules/generate.mjs`)**: The Source line appended a period after any title, so a title ending in a question mark printed `Resource?.`. The added stop is now suppressed when the title already ends in `?`, `!` or `.`, in all four renderers that print it; the general rule also corrected `DEC-04`, whose title ends the same way. A dead `formatCitation` with the same bug was deleted. `DECISIONS.md` §24 records it, including the three expressions of the rule and the trigger to revisit them.
- **Print template (`packages/prepress/src/card.typ`)**: `card.category.upper()` used a string method that Typst 0.15.1 does not provide; the call is now `upper(card.category)`, the template's only method-style string call. The PDF now builds, with every MediaBox 216 x 360 pt.
- **Source line (`packages/prepress/src/card.typ`)**: Raised from 5.5 pt to 6.5 pt, so the citation sits at body size instead of being the only type below it. It reads back at 6.5 pt on every verso and stays inside the safe inset.

## [0.1.0] - 2026-11-09

### Added
- **Canonical schema (`data/law-schema.json`)**: JSON Schema draft 2020-12 for one reference card, with `additionalProperties: false` at every object level, a fixed five-value category enum, and a nine-field card anatomy.
- **First deck records (`data/laws/*.json`)**: Six cards across five categories — Jakob's Law, the Law of Proximity, Hick's Law, Miller's Law, Fitts's Law, and the Serial Position Effect — each with an axiom, trigger, checklist, anti-pattern pair, graphic metaphor, and one primary academic source.
- **Parametric SVG generator (`scripts/svg.js`)**: Six diagram shapes (`network`, `hierarchy`, `proximity-grid`, `target-vector`, `decay-curve`, `convention-grid`) drawn from each card's `graphicMetaphor` parameters, with a 400 x 400 viewBox, `currentColor` marks, and `non-scaling-stroke` on every stroke.
- **Print template (`packages/prepress/src/card.typ`, `packages/prepress/build.mjs`)**: Typst template for a 3.00 x 5.00 in page (2.75 x 4.75 in trim plus 0.125 in bleed), a 0.1875 in safe inset, corner trim marks, and recto/verso faces. The build emits `packages/prepress/dist/ux-deck.pdf`. **The PDF has not yet been rendered: Typst is absent on the development machine.**
- **Static web viewer (`packages/web/`)**: Phone-friendly card viewer with no build step and no server. The card data and generated SVG are bundled into a classic script at build time so the page works from `file://`; cards flip to the verso by click or keyboard, and category filters narrow the deck.
- **Generated agent ruleset (`packages/rules/generate.mjs`, `rules/ux-rules.md`, `skills/ux-laws/SKILL.md`)**: The same records rendered as an actionable ruleset and as a skill with a trigger-oriented description.
- **Validation (`scripts/validate.mjs`)**: Ajv 2020 compilation of the schema, per-record error output, duplicate-ID detection, and a 15-word axiom check on top of the schema's 110-character cap. Accepts optional file paths for ad hoc checks; a deliberately broken record fails with the extra-property and missing-remediation errors.
- **PDF check (`scripts/pdf-check.mjs`)**: Structural check that every page's MediaBox is 216 x 360 pt and that the page count is twice the card count; handles raw and compressed object streams and exits 2 with a clear message when no PDF exists.
- **Web check (`scripts/check-web.mjs`)**: Headless Chrome/Chromium smoke test at a true 390 x 844 viewport, asserting no horizontal overflow, six rendered cards, a flip that exposes the verso, and a category filter that narrows to one card.
- **Licences (`LICENSE`, `LICENSE-DATA`)**: MIT for code and CC0-1.0 for card data and the schema.
- **Repository hygiene (`.gitignore`)**: Ignores `node_modules/`, Prepress build and dist output, `.DS_Store`, and the read-only `SupportingInformation/` research input.
- **Documentation (`README.md`, `CHANGELOG.md`, `DECISIONS.md`)**: Setup and verification instructions, the change record, and the reasons behind every deviation from the source specifications.

### Changed
- **Citations (`data/laws/dec-01.json`, `data/laws/mpa-01.json`)**: Each card now carries exactly one primary paper with that paper's own authors, year, title, and venue. DEC-01 cites Hick (1952), and the card is named Hick's Law to match; MPA-01 cites Murdock (1962). Merged attributions were removed deck-wide.
- **Schema requirements (`data/law-schema.json`)**: Removed `remediatedPattern` from `required[]` without declaring it, because the source schema required a property it never defined and `additionalProperties: false` made every record invalid. The `antiPattern { violation, remediation }` pair remains the single remediation field.
- **Schema identifier (`data/law-schema.json`)**: `$id` now points at the intended published URL, `https://raw.githubusercontent.com/tjmustard/knowledge-domain-decks-skills/main/data/law-schema.json`, replacing the `.example` placeholder. It is live only once this slice is merged to `main`; until then it is the intended canonical location, not a resolvable identifier.
- **Package name (`package.json`, `package-lock.json`)**: Renamed to `knowledge-domain-decks-skills` to match the repository slug.

### Fixed
- **Dead parameters (`data/laws/hmm-01.json`, `data/laws/ges-01.json`)**: Removed unused `panels` and `clusters` values from `parametricParams`; only parameters the SVG generator reads remain.
- **Page-count report (`packages/prepress/build.mjs`)**: The build log now reports the actual 12 pages (six cards, recto and verso) instead of six.
- **PDF check robustness (`scripts/pdf-check.mjs`)**: Compressed object streams are inflated before scanning, so a valid PDF is no longer misread as having no pages, and a missing PDF exits 2 with a build hint rather than a stack trace.
